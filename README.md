# Gym & Leno - موقع جيم احترافي متكامل مع لوحة تحكم إدارية شاملة

موقع ويب احترافي وفاخر لجيم **Gym & Leno**، مصمم بأعلى معايير مواقع الأندية الرياضية العالمية، ومزود بلوحة تحكم إدارية عربية بالكامل (RTL) للتحكم في كافة محتويات وأسعار وباقات وأعضاء الجيم وطرق الدفع المصرية دون الحاجة لتعديل الكود.

---

## 🌟 مميزات المشروع

### 1. الواجهة العامة للموقع (Public Landing Page)
- **تصميم عصري وفخم (Dark Luxury Aesthetic)** باللون الأسود الداكن والرمادي والرموز الفسفورية (Electric Lime) والبرتقالية.
- **خلفية فيديو سينمائية متحركة** مع صورة بديلة وتحكم في نسبة التعتيم وكاتم الصوت التلقائي.
- **شريط إعلانات وعروض تفاعلي** في أعلى الموقع.
- **عداد إحصائيات حي** للأعضاء والمدربين والبرامج ونسبة الرضا، مرتبط بقاعدة البيانات ومتحكم به من لوحة الإدارة.
- **8 برامج تدريبية احترافية**:
  - بناء العضلات والضخامة (Bodybuilding)
  - خسارة الدهون ونحت القوام (Fat Loss)
  - اللياقة البدنية العامة (General Fitness)
  - تمارين القوة ورفع الأثقال (Strength Training)
  - الكارديو وحرق السعرات (Cardio & HIIT)
  - التدريب الشخصي الخاص (1-on-1 VIP)
  - تأسيس المبتدئين وتعديل القوام (Beginners)
  - تمارين اللياقة والتحمل (Endurance & Performance)
  - نافذة منبثقة لكل برنامج لعرض المدة، المستوى، عدد الجلسات، والمدرب المشرف مع زر التسجيل المباشر.
- **فريق المدربين المعتمدين دولياً**: بطاقات للمدربين مع التقييم، التخصص، سنوات الخبرة، البرامج المشرف عليها، وحجز جلسة خاصة.
- **باقات الاشتراك والأسعار بالجنيه المصري (EGP)**:
  - اشتراك شهر واحد (Basic)
  - اشتراك 3 أشهر (Advanced)
  - اشتراك 6 أشهر (Pro Performance)
  - اشتراك سنة كاملة (VIP Elite)
  - عرض السعر الأصلي والسعر المخفض مع نسبة الخصم ومميزات كل باقة.
  - جميع الأسعار قابلة للتعديل الفوري من لوحة الإدارة.
- **نظام حجز واشتراك تفاعلي**:
  - نموذج تسجيل: الاسم، رقم الهاتف، البريد الإلكتروني، الباقة، المدرب، الفترة المفضلة (صباحية، ظهيرة، مسائية).
  - اختيار طريقة الدفع المصرية المفضلة وإرفاق رقم العملية.
  - إصدار كود طلب فريد تلقائياً (مثل `LENO-ORD-8812`) وحفظه في قاعدة البيانات بحالة "قيد المراجعة".
- **صفحة متابعة حالة العضوية والطلب (`/track`)**: يدخل المشترك رقم الهاتف أو كود الطلب لمعرفة حالة اعتماده ومواعيد الاشتراك.
- **دعم كامل للغتين (الإنجليزية كافتراضية + العربية مع اتجاه RTL بالكامل)** بضغطة زر واحدة.

### 2. لوحة تحكم الإدارة (`/admin`)
لوحة تحكم احترافية باللغة العربية تدعم RTL، محمية بنظام مصادقة وجلسات مشفرة:
- **مسار الدخول**: `/admin/login`
  - **اسم المستخدم الافتراضي**: `admin`
  - **كلمة المرور الافتراضية**: `admin123`
- **13 قسماً إدارياً متكاملاً**:
  1. **الرئيسية والإحصائيات**: عداد الأعضاء النشطين، الاشتراكات المنتهية والقريبة من الانتهاء، إجمالي الإيرادات بالجنيه، وجدول سريع لاعتماد أو رفض أحدث الطلبات.
  2. **محتوى الموقع**: تعديل عناوين ووصف الهيدر، أزرار الدعوة للإجراء، وشريط العروض باللغتين العربية والإنجليزية.
  3. **مكتبة الصور والفيديوهات**: رفع وإضافة الصور والفيديوهات، معاينتها، نسخ روابطها، وحذف غير المستخدم منها.
  4. **خلفيات الفيديو**: تغيير رابط فيديو الخلفية الحية، الصورة البديلة، ودرجة التعتيم بنظام Sliders.
  5. **الاشتراكات والأسعار**: تعديل أسعار الباقات بالجنيه المصري، نسب الخصومات، الميزات، وتفعيل أو إيقاف أي باقة.
  6. **طرق الدفع المصرية**: تفعيل وتعطيل فودافون كاش، إنستاباي، أورنج كاش، اتصالات كاش، وي باي، فيزا/ماستركارد، فوري، وتعديل أرقام المحافظ وتعليمات التحويل.
  7. **إدارة الأعضاء**: البحث بالاسم أو الهاتف أو كود العضوية، إضافة عضو يدوياً، وتعديل ومتابعة الاشتراكات.
  8. **المدفوعات والطلبات**: فحص طلبات المشتركين، أرقام الإشعارات، واعتماد الطلب الذي يُفعل العضوية تلقائياً في النظام.
  9. **البرامج والمدربون**: استعراض وإدارة البرامج والمدربين.
  10. **بيانات الاتصال**: تعديل أرقام الهواتف، رقم واتساب، العنوان، ورابط خرائط جوجل، ومواعيد العمل للأيام العادية ويوم الجمعة.
  11. **التواصل الاجتماعي**: تحديث روابط فيسبوك وإنستغرام وتيك توك ويوتيوب.
  12. **إعدادات الموقع والتصميم**: تغيير لون الإبراز (أخضر ليموني، برتقالي، أحمر، ذهبي)، شعار الموقع، وإعدادات المظهر.
  13. **الحساب والأمان**: إدارة الجلسة، وتنزيل نسخة احتياطية كاملة من قاعدة البيانات بصيغة JSON.

## 🛠️ البنية التقنية (Tech Stack)
- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS, Luxury Dark Theme, Custom Keyframes & Animations
- **Icons**: Lucide React
- **Database & Storage**: محرك تخزين محلي دائم `data/gym-db.json` مع توافق كامل ومجهز لقاعدة بيانات **Supabase PostgreSQL** و**Vercel Serverless Functions**.
- **ملف قاعدة البيانات لـ Supabase**: متوفر في ملف `supabase-schema.sql`.

## ☁️ خطوات النشر على Vercel

تم اختبار بناء المشروع بنجاح 100% بدون أي أخطاء (`npm run build` مكتمل بـ 19 مساراً ثابتاً وديناميكياً).

### الطريقة الأولى: النشر عبر GitHub وVercel (الموصى بها رسمياً)
1. قم بإنشاء مستودع جديد على حسابك في GitHub (مثلاً: `gym-leno`).
2. ارفع مجلد المشروع إليه.
3. ادخل إلى لوحة تحكم [Vercel](https://vercel.com) واضغط **Add New Project**.
4. اختر المستودع واضغط **Deploy**.
5. سيكتشف Vercel تلقائياً أنه مشروع Next.js وسيقوم بالبناء والنشر في أقل من دقيقة.

### الطريقة الثانية: النشر عبر Vercel CLI
1. تسجيل الدخول إلى Vercel من خلال الطرفية:
   ```bash
   npx vercel login
   ```
   (ستفتح لك صفحة المتصفح لتأكيد الدخول بحسابك في Vercel).
2. تشغيل أمر النشر المباشر:
   ```bash
   npx vercel --prod
   ```
3. ستحصل فوراً على رابط الإنتاج المباشر الخاص بموقعك!
